# КПМ ЦБ — адаптация квартальной прогнозной модели Банка России

Редуцированная КПМ ДДКП Банка России (5 уравнений), откалиброванная на данные
Федерации из `../data_239Q2.csv`, и решение по ключевой ставке на 239Q3.

## Запуск

```bash
pip install numpy pandas scipy
python step1_data.py     # обязательно первым — создаёт prep.csv
python answer2.py        # рабочий ответ: 5,07 %
python cbr_final2.py     # полная модель + чувствительность
python cbr_dump.py       # все коэффициенты и состояние на 239Q2
```

Пути внутри скриптов относительные (`__file__`), данные берутся из корня
репозитория, так что папку можно запускать как есть.

## Файлы

| файл | что делает |
|---|---|
| `step1_data.py` | Единицы измерения, тренды и разрывы (HP, λ=1600), знаковые проверки котировки курса. **Создаёт `prep.csv`** — вход для всего остального |
| `cbr_final2.py` | Полная модель: 5 уравнений, стэкированное решение на 40 периодов, тест стационарности, IRF, псевдо-OOS, чувствительность к спорным точкам адаптации. Пишет `cbr_decision.json` |
| `answer2.py` | Правило ЦБ (E4) на наблюдаемых вместо модельного прогноза инфляции → **5,07 %** |
| `cbr_dump.py` | Выгрузка всех приведённых коэффициентов, шоков и состояния на 239Q2 |
| `КПМ_ЦБ_система_уравнений.md` | Спецификация: все уравнения, калибровка, источники параметров, места адаптации |

## Результат

Вход на 239Q2: `RS = 5,32`, `PIE4 = 4,25`, `Y_GAP = −5,45`, `LZ_GAP = +62,15`,
нейтральная `RR_EQ = 2,23 %` (из уравнения ЦБ), цель `100·ln(1,04) = 3,92`.

| | RS на 239Q3 | скрипт |
|---|---|---|
| Правило ЦБ на наблюдаемых (ядро 4,85–5,06 %) | **5,07 %** | `answer2.py` |
| Полная КПМ, базовый режим | 0,84 % — **отвергнут** | `cbr_final2.py` |

Полная модель даёт 0,84 % потому, что её собственный прогноз инфляции на горизонте
правила уходит в дефляцию (`PIE4 = −1,29` против фактических 4,25). Причина — разрыв
выпуска −5,45 п.п. при наклоне кривой Филлипса, откалиброванном на устойчивую
экономику: модель читает такой разрыв как сильное дезинфляционное давление и просит
резкого смягчения. По псевдо-OOS этот прогноз проигрывает AR(2), поэтому в правило
подставляется наблюдаемая инфляция, а не модельная — это и даёт 5,07 %.

Чувствительность ядра (`answer2.py`): `gamma3 = 0` → 5,57 %; `RR_EQ = 1,5` → 4,82 %;
`RR_EQ = 2,5` → 5,07 %; цель 4,00 в арифметике → 4,82 %. Шаг решения кратен 25 б.п.
