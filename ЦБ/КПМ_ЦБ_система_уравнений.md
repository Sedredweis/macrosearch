# Редуцированная КПМ ДДКП Банка России: полная система уравнений

Это ровно та система, которой считалось решение по ключевой ставке (прогон 2).
Источник структуры и калибровки — `model/qpm_model.mod` и `model/parameters_main.mod`
(IRIS Toolbox, не Dynare). Всё, что не переносилось напрямую, помечено явно.

---

## 0. Единицы и соглашения

| объект | единица |
|---|---|
| ставки `RS`, `RR`, `RR_EQ` | % годовых |
| инфляция `PIE` | % годовых (кв. прирост, аннуализированный) = 400·Δln CPI |
| годовая инфляция `PIE4` | % = 100·Σ⁴ Δln CPI |
| разрывы `Y_GAP`, `LZ_GAP`, `N_GAP`, `RMC` | % (100·log) |
| цель `PIE_TAR` | 100·ln(1,04) = **3,9221** |

**Знак курса.** `LZ` строится с переворотом исходного ряда: `LZ_t = −100·Σ Δln RFX`,
чтобы рост означал **ослабление** национальной валюты — конвенция ЦБ. Основание —
знаковые тесты (перенос в цены t = −7,5; реакция на ставку t = +8,4 на исходном ряде).

Деление на 4 в уравнении UIP — перевод годовых ставок в квартальный шаг, как у ЦБ.

## 1. Блок измерения: из 13 рядов в переменные модели

Не уравнения модели, а то, как строится её вход.

```
(M1)  PIE_t    = 400 · dPC_t
(M2)  PIE4_t   = 100 · (dPC_t + dPC_{t−1} + dPC_{t−2} + dPC_{t−3})
(M3)  Y_t      =  100 · Σ dY ,      Y_GAP  = Y  − HP(Y , λ=1600)
(M4)  N_t      =  100 · Σ dL ,      N_GAP  = N  − HP(N , λ=1600)
(M5)  LZ_t     = −100 · Σ dRFX ,    LZ_GAP = LZ − HP(LZ, λ=1600)
(M6)  X_GAP, M_GAP — так же из dEX, dIM

(M7)  EW1_PIE_t = w_exp_lag·PIE_{t−1} + (1 − w_exp_lag)·PIE_{t+1}
(M8)  RR_t      = RS_t − EW1_PIE_t                     [ур. ЦБ 'RR = RS − EW1_PIE_C']
(M9)  RR_EQ_t   = HP(RR, λ=160000)                     [латентный гладкий уровень]
(M10) RR_GAP_t  = RR_t − RR_EQ_t
(M11) DF_GAP_t  = (Y_GAP_t − w_x·X_GAP_t + w_m·M_GAP_t) / w_d
```

`(M9)` — замена уравнения ЦБ `RR_EQ = λ·RR_EQ{−1} + (1−λ)·(RRF_EQ + PREM_EQ + E1_DOT_LZ_EQ)`:
`RRF_EQ` и `PREM_EQ` не наблюдаемы, поэтому `RR_EQ` оценивается как латентное состояние.

**На 239Q2:** `RR = 2,597`, `RR_EQ = 2,227`, `RR_GAP = +0,370`,
`RS_NEUTRAL = RR_EQ + PIE_TAR = 6,149 %`.

## 2. Ядро: пять уравнений

Символьная форма слева, численная (с калибровкой ЦБ и `r̄ = 2,227`) справа.

### (E1) Кривая спроса (Эйлер), `qpm_model.mod`, 'Domestic demand curve'

```
Y_GAP_t = d_lead·Y_GAP_{t+1} + d_lag·Y_GAP_{t−1} − d_rr·RR_GAP_t + FISC_t + SHCK_DF_t

RR_GAP_t = RS_t − EW1_PIE_t − RR_EQ
```

Численно:

```
Y_GAP_t = 0,20·Y_GAP_{t+1} + 0,50·Y_GAP_{t−1}
          − 0,35·RS_t + 0,0875·PIE_{t−1} + 0,2625·PIE_{t+1}
          + 0,7795 + SHCK_DF_t
```
(последний свободный член = 0,35 · r̄ = 0,35 · 2,227)

У ЦБ здесь `RRA_GAP` — средневзвешенный разрыв реальных ставок по срокам из
`qpm_term_structure.mod`. Кривой ОФЗ нет, поэтому **заменено на ставку овернайт**.
Члены `d_wr·(WR_GAP + N_GAP + d_ub·U_GAP)` и `d_tot·LTOT_GAP` выброшены — нет зарплат,
безработицы и условий торговли. `FISC_t = 0`: фискальный импульс не выделяется отдельно
и целиком поглощён `SHCK_DF_t`.

### (E2) Кривая Филлипса, `qpm_model.mod`, 'Phillips curves'

Две кривые ЦБ (`PIE_D`, `PIE_M`) плюс агрегатор схлопнуты в одну — отдельных
компонент ИПЦ нет.

```
PIE_t = c_lag_d·PIE_{t−1} + (1 − c_lag_d)·EW1_PIE_t + c_rmc_d·RMC_MA_t + SHCK_PIE_t

RMC_t    = (1 − α_m)·[α_d·N_GAP_t + (1 − α_d)·Y_GAP_t] + α_m·LZ_GAP_t
RMC_MA_t = 0,25·RMC_t + 0,50·RMC_{t−1} + 0,25·RMC_{t−2}
```

Численно:

```
PIE_t = 0,40·PIE_{t−1} + 0,60·PIE_{t+1}
        + Σ_{k=0,1,2} w_k·[ 0,13398·Y_GAP_{t−k} + 0,17052·N_GAP_{t−k} + 0,04550·LZ_GAP_{t−k} ]
        + SHCK_PIE_t ,        w = (0,25 ; 0,50 ; 0,25)
```

Коэффициент при `PIE_{t−1}` = `c_lag_d + (1−c_lag_d)·w_exp_lag` = 0,20 + 0,80·0,25 = **0,40**;
при `PIE_{t+1}` = `(1−c_lag_d)·(1−w_exp_lag)` = **0,60**. Сумма = 1 — вертикальность в
длинном периоде сохранена.

Сглаживание издержек `0,25/0,50/0,25` — единственное численное значение, раскрытое
в записках ЦБ (ИБ 2024, ур. 32, с. 12).

Полное `RMC_D_GAP` ЦБ требует запаса капитала `Δk̂`, зарплат `p̂ʷ` и относительных цен `ϱ̂` —
ни одного ряда нет, поэтому редуцировано до трёх наблюдаемых разрывов. `N_GAP` входит
**экзогенно** (см. §3), а не как эндогенная переменная: закон Оукена на этих данных не
работает (коэффициент при разрыве выпуска t = +0,43).

### (E3) UIP, `qpm_model.mod`, блок 'UIP'

```
LZ_GAP_t = (1 − w_cc)·[ EW_LZ_t − (RR_GAP_t − PREM_t)/4 ]
         + w_cc·(1 − δ_cc)·LZ_GAP_{t−1}

EW_LZ_t  = δ·LZ_GAP_{t+1} + (1 − δ)·LZ_GAP_{t−1}
```

Численно (при `w_cc = 0,75`, режим `capital_controls = true`):

```
LZ_GAP_t = 0,2000·LZ_GAP_{t+1} + 0,4250·LZ_GAP_{t−1}
           − 0,06250·RS_t + 0,015625·PIE_{t−1} + 0,046875·PIE_{t+1}
           + 0,0625·(2,227 + PREM_t)
```

Из уравнения ЦБ выброшены `RRF_GAP`, `PREM_TRANS`, `PREM_BOP`, `PREM_TOT`,
`PREM_BOP_CC` — нет зарубежной ставки, CDS-премии и данных платёжного баланса.
Всё это свёрнуто в одно латентное `PREM_t`.

### (E4) Правило ДКП, `qpm_model.mod`, 'Monetary policy rule'

```
RS_t = γ1·RS_{t−1} + (1 − γ1)·( RS_NEUTRAL_t + γ2·E3_PIE4_DEV_t + γ3·Y_GAP_t ) + RES_RS_t

RS_NEUTRAL_t   = RR_EQ + E3_PIE4_MP_t
E3_PIE4_DEV_t  = E3_PIE4_MP_t − PIE_TAR
E3_PIE4_MP_t   = PIE4_{t+3}
```

Численно:

```
RS_t = 0,75·RS_{t−1} + 0,6250·PIE4_{t+3} + 0,1250·Y_GAP_t − 0,9141 + RES_RS_t
```

Свободный член = `(1−γ1)·(RR_EQ − γ2·PIE_TAR)` = 0,25·(2,227 − 1,5·3,9221) = −0,9141.

**Единственное упрощение против ЦБ:** у них
`E3_PIE4_MP = w_mp_pie_c·E3_PIE_C4 + (1−w_mp_pie_c)·E3_PIE4` с `w_mp_pie_c = 0,75`.
Базовой инфляции отдельно нет, поэтому `w_mp_pie_c` не идентифицируется и целевой
индикатор = сводная годовая инфляция. Forward-горизонт **t+3** сохранён как у ЦБ.

Цель считается постоянной: `PIE_TAR = ψ·PIE_TAR{−1} + (1−ψ)·PIE_TAR_SS` при `ψ = 0,9999`
эквивалентно `PIE_TAR ≡ PIE_TAR_SS = 3,9221`.

### (E5) Тождество годовой инфляции

```
PIE4_t = 0,25·( PIE_t + PIE_{t−1} + PIE_{t−2} + PIE_{t−3} )
```

## 3. Экзогенные процессы и шоки

Шоки восстанавливаются **инверсией уравнений на истории**, затем проецируются вперёд.

```
(S1) SHCK_PIE_t = PIE_t − [ c_lag_d·PIE_{t−1} + (1−c_lag_d)·EW1_PIE_t + c_rmc_d·RMC_MA_t ]

(S2) SHCK_DF_t  = DF_GAP_t − [ d_lead·DF_GAP_{t+1} + d_lag·DF_GAP_{t−1} − d_rr·RR_GAP_t ]

(S3) остаток UIP:
     u_t = 4·( LZ_GAP_t − (1−w_cc)·[δ·LZ_GAP_{t+1} + (1−δ)·LZ_GAP_{t−1} − RR_GAP_t/4]
                        − w_cc·(1−δ_cc)·LZ_GAP_{t−1} )
     PREM_t   = HP(u, λ=1600)          устойчивая часть,  AR(0,9)
     RES_LZ_t = u_t − PREM_t           iid, в прогнозе = 0
```

Разделение `(S3)` воспроизводит структуру ЦБ: у них `std_RES_PREM = 1,0` с `ρ = 0,9`
и отдельно `std_RES_LZ_GAP = 10` как iid. Без разделения весь остаток проецируется
как устойчивый и разносит модель.

**Проекция вперёд** (h = 1, 2, …):

```
SHCK_PIE_{t+h} = SHCK_PIE_t · 0,50^h          ρ_shck_pie_d ЦБ
SHCK_DF_{t+h}  = SHCK_DF_t  · 0,50^h          ρ_shck_d_gap ЦБ
PREM_{t+h}     = PREM_t     · 0,90^h          ρ_prem_eq ЦБ
N_GAP_{t+h}    = N_GAP_t    · 0,94^h          оценено на данных
RES_RS_{t+h}   = 0
```

**Значения на 239Q2:**

| | значение | с.к.о. на выборке | калибровка ЦБ |
|---|---|---|---|
| `SHCK_PIE` | −1,375 | 3,65 | std 1,50 |
| `SHCK_DF` | −1,826 | 2,62 | std 1,00 |
| `PREM` (устойчивая) | **+63,957** | 18,99 | std_RES_PREM 1,0 |
| `RES_LZ` (iid) | — | 51,07 | std_RES_LZ_GAP 10 |
| `N_GAP` | −8,117 | 7,69 | — |

Волатильность курсовых шоков Федерации в **5 раз** выше калибровки ЦБ — это и есть
причина, по которой полная модель не переносится (см. §6).

## 4. Решение системы

Модель линейна и содержит опережающие члены `Y_GAP_{t+1}`, `PIE_{t+1}`, `LZ_GAP_{t+1}`,
`PIE4_{t+3}`. Итерации по ожиданиям на forward-looking системе не сходятся, поэтому
решается **стэкированная система целиком**:

* вектор состояния периода `x_h = [Y_GAP, PIE, LZ_GAP, RS, PIE4]′`, 5 переменных;
* горизонт `N = 40` кварталов → 200 неизвестных;
* лаги при `h < 0` берутся из данных, опережения при `h ≥ N` — из терминального условия
  **«плато»**: `x_h = x_{N−1}`;
* один вызов `np.linalg.solve` — точное совершенное предвидение.

**Проверка стационарности пройдена:** при нулевых шоках и равновесном стартовом состоянии
`max|Y_GAP| = 4,2·10⁻¹⁵`, `max|PIE − PIE_TAR| = 4,9·10⁻¹⁵`, `max|RS − RS_ss| = 7,1·10⁻¹⁵`.

**IRF на шок ДКП +1 п.п.:** пик дезинфляции на h = 3–4, сила −0,47 п.п.
В данных (local projections): пик h = 5, сила −0,45 п.п.

## 5. Как из системы выходит решение по ставке

Два режима:

**(а) Правило внутри контура.** `RES_RS ≡ 0`, уравнение (E4) активно с `h = 0`.
Тогда `RS_0` — это и есть предписание модели. Даёт **0,84 %**.

**(б) Ставка периода 0 задана.** Строка (E4) при `h = 0` заменяется на `RS_0 = i_targ`,
правило работает с `h = 1`. Используется для сценариев и для оптимизации по сетке.

**Стартовое состояние на 239Q2:**

```
RS_{−1}    = 5,3227        PIE4_{−1} = 4,2539
PIE_{−1..−4} = 2,538 ; 3,291 ; 4,783 ; 6,404
Y_GAP_{−1..−3}  = −5,452 ; −5,043 ; −5,776
```

## 6. Почему рабочий ответ взят не из полной модели

Полная система даёт `RS(239Q3) = 0,84 %` и уводит траекторию до −4,8 % (ЗНП в КПМ нет).
Причины отвергнуть:

* **псевдо-OOS**: RMSE годовой инфляции 3,3 → 15 против 1,0 → 2,0 у AR(2);
* **разброс по вариантам адаптации −3,3 … +25,7 %** — модель на этих данных не
  идентифицирована;
* механика: `LZ_GAP = +62` лог-пунктов, прогоняемый через издержки с весом
  `α_m·c_rmc_d = 0,0455`, даёт +2,9 п.п. к инфляции, и модель ждёт её обвала при
  схлопывании разрыва.

Поэтому решение берётся из **уравнения (E4) в его собственной форме, но с наблюдаемым
входом вместо модельного прогноза**:

| чем брать `E3_PIE4` | значение | `RS` |
|---|---|---|
| текущая `PIE4` | 4,25 | **5,06 %** |
| прогноз AR(2) на 3 кв. | 4,10 | **4,96 %** |
| ожидания заякорены на цели | 3,92 | **4,85 %** |
| прогноз самой КПМ | −1,29 | 1,59 % (отвергнут) |

## 8. Что в этой системе самое хрупкое

1. **`w_cc`** — при `w_cc = 0` решение уходит с 0,84 % на 25,69 %. Единственный самый
   мощный параметр.
2. **`LZ_GAP`** — от +17 (HP 400) до +105 (HP 16000) в зависимости от фильтра;
   решение от −1,96 % до +3,44 %.
3. **`RR_EQ`** — ±1 п.п. даёт ±0,4 п.п. в решении по правилу.
4. **`α_m·c_rmc_d`** — перенос курса в цены. При `α_m = 0,05` (как в данных Федерации)
   решение падает до −3,29 %.
5. **`PREM`** — при обнулении решение −0,85 % вместо 0,84 %.
