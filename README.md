Структура репозитория

0) data_239Q2.csv - теоретические данные
1) svar_soe.py - модель SVAR soe
2) run_analysis.py - запуск визуализации и расчета ставки инфляции и IRF откликов
3) SVAR.py - ковариационные матрицы и все уравнения с вычисленными коэффициентами из SVAR модели
4) SVAR_MODEL_FINAL.py - интерактивный файл с пользовательским интерфейсом для моделирования шоков, задания траектории ставки, просмотра вычисленных уравнений и лагов
